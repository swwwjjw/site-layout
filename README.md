# Student Hub

Простой учебный многостраничный сайт на HTML и CSS.

## Структура

- index.html — главная страница
- tasks.html — практические задания
- coursework.html — курсовая работа
- about.html — информация о сайте
- css/style.css — общие стили
- images/ — изображения

## Запуск

Откройте `index.html` в браузере.

## GitHub Pages

1. Создайте новый репозиторий на GitHub.
2. Загрузите все файлы и папки проекта.
3. Откройте Settings → Pages.
4. В разделе Build and deployment выберите Deploy from a branch.
5. Выберите ветку `main` и папку `/ (root)`.
6. Сохраните настройки.

После публикации GitHub Pages выдаст адрес сайта.
