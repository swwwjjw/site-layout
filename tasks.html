Практические задания

На этой странице собраны учебные работы.

Практическая работа №1. База данных

Проектирование структуры базы данных для выбранной предметной области. В работе необходимо определить сущности, атрибуты, ключи и связи между таблицами, а затем реализовать структуру с помощью SQL.

Технология: PostgreSQL, SQL

Практическая работа №1.2. Типы данных

Изменение существующей структуры базы данных. Работа с типами date и integer, добавление автоматически создаваемого идентификатора и установка необходимых ограничений.

Технология: PostgreSQL

Задание №4. REST API

Проектирование внешнего REST API для сервиса авиабилетов. Рассматриваются HTTP-методы, URL ресурсов, query-параметры, сортировка, пагинация, коды ошибок и структура JSON-ответов.

Технология: HTTP, REST, JSON

Практическая работа. Компьютерные сети

Изучение основных сетевых технологий и принципов взаимодействия устройств. Отдельное внимание уделяется удаленному доступу к сетевому оборудованию и базовым протоколам.

Технология: Cisco IOS, TCP/IP

Работа над заданиями

Выполнение практических заданий помогает постепенно переходить от теоретических знаний к самостоятельной работе. Сначала определяется предметная область и требования, затем выбираются подходящие технологии. После этого создается решение, выполняется проверка и исправляются ошибки.

Важно не только получить рабочий результат, но и оформить его так, чтобы другой человек мог понять логику решения. Поэтому в учебных работах полезно оставлять комментарии, давать понятные названия объектам и соблюдать единый стиль оформления.

Полезные навыки

Программирование

Умение читать код, находить ошибки и понимать общую логику программы.

Командная работа

Обсуждение требований, распределение задач и согласование результата.

Организация

Понятная структура файлов, документации и материалов проекта.
