О проекте

Tasks Hub - платформа, объединяющая в одном месте материалы, задания и результаты работы студента.

Во время обучения студентам приходится работать с разными технологиями. Отдельно изучаются базы данных, основы программирования и сетевые технологии. Для каждой дисциплины появляются практические задания, поэтому удобная структура хранения информации становится необходимостью.

Учебный процесс

Теория и практика

Учебный процесс состоит не только из лекций. Большую роль играют практические занятия, во время которых необходимо самостоятельно разобраться с поставленной задачей. Например, при изучении баз данных важно не просто знать определения первичного и внешнего ключа, а уметь применить их при создании настоящей структуры базы данных.

Аналогичный подход используется при изучении веб-разработки. HTML отвечает за структуру страницы, CSS позволяет оформить внешний вид, а JavaScript в дальнейшем может использоваться для реализации интерактивного поведения. Поэтому данный проект можно считать первым этапом перед созданием более функционального серверного приложения.
