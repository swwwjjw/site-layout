О сайте

Для чего создан этот сайт?

Я создал Tasks Hub как решение задания 1 по курсу "Верстка и прототипирование сайтов". Его главная задача - показать мои базовые навыки HTML и CSS: создание структуры страницы, работу с блоками, изображениями, текстом, ссылками и навигацией.

При создании проекта использовалась обычная семантическая структура: header отвечает за шапку, nav - за меню, main содержит основное содержание, section используется для отдельных смысловых блоков, а footer находится в нижней части страницы.

Единый стиль достигается за счет общего файла CSS, который подключается к каждой HTML-странице. Поэтому изменение цвета, размера шрифта или другого элемента можно сделать в одном месте.

Используемые технологии

HTML5 - структура страниц. CSS3 - оформление и адаптивная верстка. Flexbox и CSS Grid используются для расположения блоков.

Что можно добавить позже?

Например, можно создать серверную часть, подключить PostgreSQL и хранить задания в базе данных. Страница «Задания» тогда будет формироваться на основе информации из базы, а администратор сможет добавлять и изменять записи.

Еще одним вариантом развития может стать система регистрации. Пользователь сможет войти в свой аккаунт, посмотреть список работ и отметить задания, которые уже были выполнены. Так простой статический учебный сайт постепенно превратится в небольшую информационную систему.
